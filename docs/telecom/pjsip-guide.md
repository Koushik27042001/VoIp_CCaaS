# PJSIP Guide

PJSIP is the Asterisk SIP stack used by this project.

## Why PJSIP

PJSIP supports:

- Modern endpoint configuration.
- WebRTC browser endpoints.
- SIP trunks.
- Registration/contact inspection.
- Better production behavior than legacy `chan_sip`.

## Browser Endpoint Requirements

Browser SIP through SIP.js requires WebSocket/WSS transport and WebRTC-compatible endpoint options.

Generated endpoint settings include:

```ini
webrtc=yes
use_avpf=yes
media_encryption=dtls
dtls_auto_generate_cert=yes
ice_support=yes
rtcp_mux=yes
direct_media=no
force_rport=yes
rewrite_contact=yes
rtp_symmetric=yes
```

## Generated WebRTC Endpoint Shape

Generated by:

- `backend/src/services/telecom/sipRouting.js`

Generated endpoint example:

```ini
[1001-auth]
type=auth
auth_type=userpass
username=1001
password=agent1001

[1001-aor]
type=aor
max_contacts=1
remove_existing=yes
qualify_frequency=30

[1001]
type=endpoint
transport=transport-wss
context=from-internal
disallow=all
allow=opus,ulaw,alaw
auth=1001-auth
aors=1001-aor
webrtc=yes
```

## Generated Transport Shape

```ini
[transport-udp]
type=transport
protocol=udp
bind=0.0.0.0:5060

[transport-wss]
type=transport
protocol=wss
bind=0.0.0.0:8089
```

Production note:

- WSS requires Asterisk HTTP/TLS configuration.
- Browser SIP should use `wss://`, not insecure `ws://`, in production.

## SIP Trunks

Provider trunk config is generated by:

- `backend/src/services/asterisk/generateSipConfig.js`

Development output:

- `backend/generated/asterisk/pjsip_custom.conf`

Trunk generation supports:

- Registration trunks.
- IP-auth style identify sections.
- Codecs.
- Transport.
- From user/domain.
- Context.
- Credential redaction in API responses.
- Optional encrypted storage.

## Verification

```bash
asterisk -rx "pjsip show transports"
asterisk -rx "pjsip show endpoints"
asterisk -rx "pjsip show aors"
asterisk -rx "pjsip show contacts"
asterisk -rx "pjsip show registrations"
```

Browser registered correctly when:

- `pjsip show contacts` shows the extension.
- The contact address references WebSocket/WSS.
- The endpoint is reachable or available.
